วิธีการเชื่อมต่อและดึงข้อมูลสดจาก Google Sheet ของคุณ

คุณสามารถแก้ไขข้อมูลบน Google Sheet แล้วให้หน้านี้อัปเดตแบบอัตโนมัติได้ง่ายๆ เพียง:
1. เปิดไฟล์ Google Sheet ของคุณ → เมนู ไฟล์ (File) → แชร์ (Share) → เผยแพร่ไปยังเว็บ (Publish to web)
2. เลือกรูปแบบเป็น ค่าที่คั่นด้วยจุลภาค (.csv) แล้วกดเผยแพร่
3. นำลิงก์ที่ได้มากรอกในปุ่ม "Google Sheets" ด้านบน ระบบจะดึงข้อมูลมาประมวลผลทันที

ระบบแดชบอร์ดประมวลผลข้อมูลสารสนเทศสุขภาพและสถิติบำบัดรักษา © 2568 | ข้อมูลตัวอย่าง จ.ศรีสะเกษ

รองรับการซิงค์ข้อมูลสดจาก Google Sheets, CSV, และ Next.js Integration

เชื่อมต่อ Google Sheets (อ่าน & บันทึกแก้ไข)

รองรับการดึงข้อมูลสด และส่งข้อมูลที่แก้ไขกลับไปบันทึกลง Sheet

* ไปที่ Google Sheet → ไฟล์ (File) → แชร์ (Share) → เผยแพร่ไปยังเว็บ (Publish to web) → เลือก CSV

หรือต้องการวางข้อมูลดิบ (Paste CSV) โดยตรง
วิธีตั้งค่าให้ Google Sheet รับบันทึกข้อมูลอัตโนมัติ (ทำครั้งเดียว):
1. ใน Google Sheet ของคุณ → กดเมนู ส่วนขยาย (Extensions) → Apps Script
2. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดด้านล่างนี้
3. กด ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New Deployment) → เลือกประเภท เว็บแอป (Web app)
4. ตรงช่อง "ผู้มีสิทธิ์เข้าถึง" ให้เลือกเป็น "ทุกคน (Anyone)" แล้วกด Deploy → คัดลอก Web App URL มาใส่ช่องข้างล่าง 
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.clearContents();
  sheet.appendRow(["ปี", "อำเภอ", "หมู่บ้าน/ชุมชน", "ผู้ป่วยเข้ารับบำบัด"]);
  data.forEach(function(row) {
    sheet.appendRow([row.year, row.district, Number(row.community), Number(row.patients)]);
  });
  return ContentService.createTextOutput(JSON.stringify({status: "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}
